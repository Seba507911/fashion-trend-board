## 선별 전략 요약

```
[런웨이 — 트렌드 원천]
  Vogue 622개 중 132개 선별 (T1~T5 집중, 21%)
  → 업계 영향력 상위 디자이너만 수집하여 트렌드 시그널 품질 확보

[마켓 — 전파 검증]
  무신사 2,883개 중 199개 선별 (의류 중심, 73%)
  → 디자이너/캐주얼 브랜드 중심 (트렌드 민감)
  → 매스 브랜드는 "대중화 완료" 확인 용도
  → 전체 볼륨은 Snowflake 전수 모니터링으로 보완

[핵심 원칙]
  수집 대상 = "트렌드에 민감한 브랜드"만 선별
  전체 볼륨 = Snowflake 데이터로 별도 추적
  → 깊이(선별 크롤링) + 넓이(전수 키워드 모니터링) 병행
```

## 2. 달성한 것과 아직 남은 것

### 달성 (인프라 90%)

- **멀티소스 런웨이 데이터**: TagWalk(프론트 샷) + Vogue(디테일 샷) 이중 수집 체계 구축
- **AI 자동 분석**: 10,094개 런웨이 룩을 Claude Vision으로 아이템/실루엣/컬러/소재 자동 라벨링
- **전문가 교차 검증**: WGSN 77건 리포트 → 101개 키워드 추출, Pool A/B 분류
- **팀 동료 정성 검증**: 26SS 33브랜드 × 10 키워드 매트릭스 — AI 분석 결과와 실제 트렌드 **상당 부분 일치** 확인
- **자동 크롤링 인프라**: 35개 브랜드 마켓 크롤러 (Cafe24/Shopify/Custom)

### 미달성 (핵심 가설 검증)

- **트렌드 전파의 정량적 증명**: "런웨이 키워드가 실제로 전파된다"를 시간축 데이터로 아직 못 보여줌
- **셀럽/인플루언서 데이터**: DB 스키마만 존재, 데이터 비어있음
- **시간축 추적**: 시즌별 변화 데이터 미구축 (현재 스냅샷만)

## 3. 방향 전환 (4/9 결정)

### 전환 전

- 데이터 수집 확대에 80% 시간 투자 (Hyperbrowser 도입, 브랜드 확장 등)
- 5단계 파이프라인 전체 검증 (런웨이→전문가→셀럽→검색→마켓)
- 전체 마켓 브랜드(매스+스포츠+캐주얼) 대상 분석

### 전환 후

- **Runway-led 전파 증명에 집중**
- 4단계 검증: **런웨이 → 셀럽/인플루언서 → 디자이너 브랜드 → 일반 SNS**
- 매스 브랜드 제외, **디자이너 브랜드 중심** 검증

### 왜 매스 브랜드가 아닌 디자이너 브랜드인가?

| 요인 | 매스 브랜드 (Nike, Zara 등) | 디자이너 브랜드 (Youth, Coor 등) |
|------|--------------------------|-------------------------------|
| 의사결정 속도 | 대조직, 다층 승인 | 소수 인력, 빠른 결정 |
| 생산 리드타임 | 6~12개월 (벤더 의뢰) | 1~3개월 (자체/소규모) |
| 트렌드 반영 | 1~2시즌 지연, 간혹 오해석 | 실시간~1시즌, 자기 해석 |
| 데이터 의미 | "생산 사이클 결과" 측정 | **"실제 트렌드 수용/감도"** 측정 |

매스 브랜드에서 키워드가 나타나는 건 "전파"가 아니라 이미 결정된 **생산 사이클의 결과**일 수 있음. 반면 소규모 디자이너 브랜드가 빠르게 채택하는 건 **진짜 트렌드 감도**를 반영함.

## 4. 비즈니스 가치 분석

### 이미 증명된 가치

**"AI가 런웨이 트렌드를 전문가 수준으로 읽어낸다"**

- 기존: 전문가 1~2명이 쇼를 직접 보고 리포트 작성 (주관적, 노동집약적)
- FTIB: AI가 61K+ 이미지를 자동 분석 → 브랜드 × 키워드 매트릭스 자동 생성
- 비용: WGSN 연간 구독 수천만원 vs AI 분석 API 비용 수십만원

팀 동료 검증 결과, AI가 추출한 26SS 키워드(레더 22/33, 시어 20/33, 크롭 19/33 등)가 실제 시즌 트렌드와 상당 부분 일치.

### 증명 시 열리는 가치

**"트렌드 전파 타이밍을 데이터로 예측한다"**

| 활용 시나리오 | 비즈니스 임팩트 |
|-------------|---------------|
| 상품기획 타이밍 | "이 트렌드는 지금 셀럽 단계 → 3개월 후 마켓 도달 예상" → 선제 기획 |
| 바잉 의사결정 | "22/33 런웨이 채택 + 셀럽 12명 착용 → 높은 확산 확률" → 근거 기반 바잉 |
| 마케팅 타이밍 | "이 키워드가 SNS 확산 직전" → 캠페인 최적 시점 포착 |
| 리스크 회피 | "Viral 패턴(단명) → 대량 생산 부적합" → 과잉 투자 방지 |

### 대형 패션회사 내부 가치

#### 1단계: 트렌드 인텔리전스 (현재 가능)

| 부서 | 활용 |
|------|------|
| 상품기획팀 | 다음 시즌 키 아이템/소재/컬러 방향 — 런웨이 키워드 매트릭스 참조 |
| 디자인팀 | 런웨이 레퍼런스 이미지 탐색 — Vogue 디테일 샷 47K + VLM 태그 검색 |
| 마케팅팀 | 트렌드 키워드 기반 캠페인 기획 — 키워드별 전파 단계 참조 |

#### 2단계: 의사결정 지원 (전파 증명 후)

| 기존 방식 | FTIB 방식 |
|----------|----------|
| 바이어 감각으로 "레더를 밀자" | "22/33 런웨이, 셀럽 12명, 디자이너 7개 출시 → 높은 확신" |
| 부서 간 회의로 "시어를 스포츠에도?" | "럭셔리→스트리트 전파 중, 스포츠 도달은 2시즌 후 예상" |
| 경험 기반 토론으로 "이건 될까?" | "전파 진행도 75%, 디자이너 브랜드 상품화 확인 → 투자 적합" |

#### 3단계: 조직 경쟁 우위 (고도화 후)

- **타사 대비 6~12개월 선행**: 런웨이→셀럽 단계에서 포착하면 매스 브랜드 생산 리드타임 이전에 기획 가능
- **"감각"에서 "근거"로**: 조직 의사결정 패러다임 전환
- **누적 자산**: 매 시즌 데이터가 쌓이면서 예측 정확도 누적 개선

#### 멀티브랜드 기업 특수 가치

다수 브랜드를 운영하는 대기업의 경우:
- **브랜드별 트렌드 수용 타이밍이 다름**: 각 브랜드가 같은 트렌드를 다른 시점에 받아들여야 함 → 조닝별 전파 추적이 직접적 가치
- **중앙 인텔리전스 허브**: 각 브랜드 상품기획팀이 개별 조사하는 대신, FTIB가 공통 데이터 소스 역할
- **기획 캘린더 연동**: FTIB 타임라인이 각 브랜드의 기획 사이클에 맞춰 "지금 기획해야 할 트렌드"를 제안

## 5. 향후 로드맵

```
4/14  셀럽/인플루언서 풀 확정 + 수집 방법 정의
4/21  디자이너 브랜드 검증 대상 확정 + VLM 세분화
5/2   ★ 핵심 트렌드 5~10개 사례 증명 (시간축 타임라인) — 1차 마일스톤
5/16  Trend Flow 실데이터 대시보드
5/30  셀럽/SNS 모니터링 통합
```

### 1차 마일스톤 (5/2): 이것이 프로젝트의 분기점

**5~10개 핵심 트렌드에 대해**:
- 런웨이(24SS~26SS)에서 언제 처음 나타났는지
- 어떤 셀럽이 언제 착용했는지
- 어떤 디자이너 브랜드가 언제 상품화했는지
- 일반 SNS에서 언제 확산되었는지

이 **시간축 타임라인**을 데이터로 보여주면 → 프로젝트의 핵심 가설이 증명됨.

## 6. 리스크와 솔직한 평가

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 전파 정량화가 안 될 경우 | 프로젝트가 "이미지 뷰어+크롤러"에 머뭄 | 5~10개 사례부터 시작, 전체가 아닌 일부만 증명해도 가치 |
| 셀럽 데이터 확보 어려움 | 전파 경로 중간이 비어짐 | 수동+타팀 SNS 데이터 연계로 시작 |
| VLM 키워드가 너무 범용적 | 매칭 결과가 뻔해짐 | Vogue 디테일 샷 활용 → 구체적 아이템 수준으로 세분화 |
| 시간축 데이터 부재 | 현재 스냅샷만으로는 "전파"를 보여줄 수 없음 | 과거 시즌(24SS~25FW) 데이터로 소급 분석 |

### 솔직한 결론

> **FTIB는 "데이터"는 충분하고, "질문"도 맞는데, "답"을 아직 보여주지 못한 상태입니다.**
>
> 83,103 데이터 포인트와 10개 대시보드 페이지 — 인프라는 훌륭합니다.
> 팀의 정성적 확신("런웨이 트렌드가 실제로 전파된다")도 있습니다.
>
> 남은 것은 **이 확신을 5~10개 구체적 사례로 시간축에 놓아 정량적으로 보여주는 것**입니다.
>
> 이것이 되면, 패션 기업 내에서 **"트렌드를 데이터로 이야기할 수 있는 최초의 내부 도구"**로 자리매김할 수 있습니다.

## 논의 포인트

3. **디자이너 브랜드 선정**: Youth, Coor, Mardi 외에 어떤 브랜드가 적합?
4. **타 팀 연계**: SNS 수집 팀의 데이터를 어떤 형태로 받을 수 있나?
5. **5/2 마일스톤**: 어떤 키워드 5~10개를 최우선 증명 대상으로 할 것인가?

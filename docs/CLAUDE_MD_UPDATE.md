## 프로젝트 방향성 재정립 (2026-04-14)

### 핵심 가치 재정의

FTIB의 핵심 가치 = **"런웨이+전문가 시그널이 실제 마켓에 언제, 얼마나 반영되는지 검증하는 것"**

검증 사이클: `런웨이 트렌드 키워드 → 셀럽/인플루언서 채택 → 마켓 반영` 의 타이밍과 매칭률을 정량적으로 추적하는 것이 최우선 과제.

### 주요 전환 사항

1. **전수분석 → 조닝별 디자이너 프리셋**
   - 38개 디자이너 전체 분석 대신, 조닝별 영향력 디자이너 10~20개를 프리셋으로 구성
   - 럭셔리 프리셋 5개(Prada, Miu Miu, Chanel, Saint Laurent, Loewe)로 26SS 분석 시 트렌드 시그널 충분히 확인됨
   - 유저가 자기 브랜드 조닝에 맞는 프리셋을 선택하거나 커스텀 구성 가능

2. **UX: 브리핑 퍼스트**
   - 탐색 도구보다 큐레이션된 브리핑(핵심 시그널 5~10개)을 먼저 보여주는 UX 우선
   - 드릴다운 탐색은 브리핑에서 관심 키워드 클릭 시 진입

3. **보류 항목**
   - 5-signal confidence 점수 체계 → 데이터 검증 완료 후 활성화
   - Origin 자동 분류 프레임워크 → 데이터 검증 완료 후 활성화
   - Market-organic Origin → 마켓 브랜드 수집 + SNS 수집 강화 후 향후 과제로 유지

### Snowflake 검증 작업

회사 Snowflake MKT 스키마의 데이터를 활용하여 런웨이 키워드 → 마켓 반영 검증 진행.

#### 핵심 검증 테이블 (3개)

| 테이블 | 용도 | 주기 |
|--------|------|------|
| `DW_MUSINSA_PRDT_RNK_W` | 무신사 주간 상품 랭킹 — 상품명에서 트렌드 키워드 매칭 | 주간 |
| `MST_KWD_NAVER_SRCH_W` | 네이버 키워드 주간 검색량 — 키워드별 검색 추이 | 주간 |
| `MW_NAVER_SHOPPING_TREND_KWD` | 네이버 쇼핑 트렌드 키워드 — 카테고리별 인기 키워드 등장 | 주간 |

#### 보조 테이블

| 테이블 | 용도 |
|--------|------|
| `MW_NAVER_SHOPPING_POPULAR_BRAND` | 카테고리별 인기 브랜드 랭킹 변화 |
| `MW_NAVER_SEARCH_RLTD_KWD` | 연관 검색어 — 트렌드 확산 패턴 |
| `MW_NAVER_SEARCH_AUTO_KWD` | 자동완성 키워드 — 소비자 관심 초기 신호 |
| `KWD_SCL_POST_CNT_W` | SNS 포스트 수 기반 키워드 버즈량 |
| `CTGR_SALES_W` | F&F 자사 카테고리별 실제 판매량 (최종 검증) |

#### 제외 테이블

- 인플루언서 관련 테이블 (`DW_INFLUENCER_*`, `DW_CAMPAIGN_*`, `EXT_INSTAGRAM_*`, `VW_CONTENT_BASE`) — 자사 소규모 크루 활동 데이터로 트렌드 시그널 용도에 부적합

#### 테스트 키워드

검증 파일럿으로 2개 키워드 유형 테스트:
- **레더자켓** (아이템 단위) — 동의어: 레더, leather, 가죽, 레더자켓, 가죽자켓
- **시어** (속성 단위) — 동의어: 시어, 시스루, sheer, see-through, 투명

아이템 키워드 vs 속성 키워드의 매칭률 차이를 비교하여 향후 전체 키워드 검증 방법론 결정.

#### 검증 시나리오

1. **런웨이 키워드 → 무신사 랭킹 침투율**: PRODUCT_NAME 텍스트 매칭으로 랭킹 진입 상품 수 주간 추이
2. **런웨이 키워드 → 네이버 검색 스파이크 타이밍**: 검색량 시계열에서 런웨이 쇼 이후 반응 시점
3. **쇼핑 트렌드 키워드 등장 여부**: 네이버 쇼핑 인기 키워드에 런웨이 키워드가 언제 등장하는지

데이터 기간: 2024년 이전 ~ 현재 (주간/월간 적재 진행 중)
